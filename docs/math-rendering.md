# 公式显示

会话支持 KaTeX 格式的行内公式 `$...$`、`\(...\)` 和独立公式 `$$...$$`、`\[...\]`。多行公式、对齐公式、矩阵和 Markdown 表格中的公式可显示；公式字号跟随页面字号，过宽公式在自己的区域内滚动。

代码块和行内代码保持原样。未闭合、语法错误、不支持或超过资源限制的表达式会保留为可读源码。此功能处理的是 Markdown 公式子集，不是完整 TeX 文档。

渲染不启用 HTML 或 URL 命令。单条消息最多绘制 128 个公式；表达式、行数和宏展开均有上限。资源缺失或公式不适用时回退显示源码，不影响其他会话内容。

KaTeX、样式、许可文件和字体随本地静态资源分发，不从数学公式 CDN 加载。开发者可在完整源码仓库运行 `npm run vendor:math` 更新供应资源；资源清单和静态文件加载规则由应用校验。修改资源后应按[开发验证指南](verification.md)检查打包结果。
