# 临时 HTTPS 手机访问

此方式供本机源码使用者临时从手机访问同一台电脑上的 Codex。它不需要 VPS、固定域名或手机应用，但 Quick Tunnel 地址会变化，不能作为长期固定入口。手机端只应连接你自己的可信电脑和服务。

## 启动与登录

1. 在运行 Codex 的电脑上按仓库根目录 [README](../README.md#开发者) 安装依赖。首次启动需要在 Codex 桌面任务环境执行，以便保存当前任务关联；不要手动填写任务 ID。
2. 选择访问范围后启动桥接。只读访问可直接在 Codex 任务环境运行 `npm start`；如需手机端发送消息，先设置以下选项再启动，允许向本机全部普通会话发送：

   ```powershell
   $env:BRIDGE_ENABLE_SEND = '1'
   $env:BRIDGE_SEND_SCOPE = 'all-local'
   npm start
   ```

   首次启动保存的任务关联、端口和发送范围位于忽略版本控制的 `.local/runtime.json`。之后可从项目目录运行 `npm run start:background` 启动桥接。
3. 如项目内还没有 `cloudflared`，在项目目录运行 `npm run remote:install`。该命令将官方运行文件放入忽略版本控制的 `.local/tools`，不修改系统 PATH，也不注册 Windows 服务。
4. 在本机网页侧栏打开“手机访问设置”，明确点击“开启手机访问”。页面显示访问密码和临时 HTTPS 地址；首次地址生效可能需要几十秒。
5. 在手机浏览器打开该地址并使用访问密码登录。刷新本机页面不会再次显示原密码，但已保存的密码仍有效。遗失时关闭入口再开启，以生成新密码。

“退出登录”只撤销当前设备；“撤销全部登录”会要求所有设备重新登录。关闭手机入口会结束隧道并撤销所有登录，下次开启会生成新密码。登录请求丢失响应、隧道断线或桥接重启都不会自动重发聊天操作。

## 安全与限制

访问口令以加盐 scrypt 保存，登录会话只保存令牌哈希，最长 7 天、最多 10 个，并启用全局登录尝试限流。远程网关不提供开启手机入口的管理接口。不要把本机桥接端口 `4317` 直接映射到公网；隧道连接的是有独立登录保护的 `4318` 网关。

隧道断开后会尝试重建，并在本机设置中更新地址；地址变化时，手机无法通过旧收藏自动发现新网址。此模式只提供临时 HTTPS 访问，不是 VPS 多账号服务。电脑必须开机、联网，Codex 与桥接必须运行；登录前控制、自动开启 Codex、睡眠唤醒和断电恢复不受支持。
