# 手机模型与推理强度

消息输入区的模型菜单列出当前 Codex 桌面支持的模型，并提供该模型可用的推理强度。创建会话和开始下一轮时可明确选择；不选择时沿用电脑端 Codex 设置。选择只作用于提交的新一轮，不改写 Codex 的全局默认值。

选择按当前账号、设备和会话保存在浏览器会话中。切换设备或账号时使用对应的选择。模型或强度不再受当前桌面支持时，不会静默改用其他选项；请重新打开菜单选择可用值。

运行中的任务不能变更当前轮次。向运行中的会话补充消息会沿用当前轮设置，已选模型用于之后可开始的新一轮。会话权限选项的作用范围另见[会话上下文与权限](thread-context-permissions.md)。

模型目录由运行该会话的 Codex 实例提供。桌面版本或模型配置变化后，网页读取到的新目录可能不同；不支持原生模型覆盖时，页面会报告不可用。模型提供方与 API 凭证仍由本机 Codex 管理，不会保存在 Hub。
