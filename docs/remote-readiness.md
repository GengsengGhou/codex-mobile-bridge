# 离开电脑后的可用性验收

当前目标是在电脑已开机、联网且 Codex 已打开时，通过手机网页继续工作。电脑自动登录、启动 Codex 与唤醒不属于当前使用条件。以下记录分别标明接口、桌面与真实手机的验收程度。

## 日常工作

| 场景 | 当前状态 | 验收要求 |
| --- | --- | --- |
| 继续桌面已有任务 | 已有真实往返记录 | 手机输入进入相同任务，桌面回复同步出现 |
| 运行中补充或停止 | 已有隔离任务真实记录 | 停止前核对轮次，不能误停下一轮 |
| 回答模型的问题 | 异步问题空闲/运行中真实往返通过；标准问题有模拟验证 | 支持标准问题和异步问题；回答能被原任务接收 |
| 批准或拒绝具体操作 | 已接入，有模拟验证；尚无真实工具审批验收 | 展示命令、目录或文件变更；由用户明确决定 |
| 桌面和网页同时处理问题 | 请求变化与桌面实例变化有自动测试 | 已失效的请求不可再次提交，新的请求不可套用旧答案 |
| 新建会话和选择项目 | 已实现；真实本机项目创建、自动进入、首条回复与重启后回执通过 | 手机能启动新工作，不依赖预先在电脑创建会话；尚需真实手机浏览器验收 |
| 查看或下载文件 | 已实现当前会话工作目录浏览、本地文件链接与文本/图片/PDF预览；真实手机浏览器尚待验收 | 手机能查看或下载允许访问的结果，目录外文件不能越界读取 |
| 上传附件 | 已实现；真实上传、丢失回执后刷新恢复与服务重启后回执/文件通过 | 上传到会话工作目录，明确发送后交给模型读取；真实手机选择器与模型读取附件尚待验收 |
| 查看与恢复归档 | 已实现；真实列表读取通过，恢复有接口/DOM测试 | 手机能找回已归档会话；不明结果不自动再次操作；真实业务归档未做变更试验 |

## 中断与恢复

| 场景 | 当前状态 | 验收要求 |
| --- | --- | --- |
| 发送后断网或刷新 | 已有自动测试 | 保留草稿和待核对记录，只查回执、不自动重发 |
| 提交审批或答案后断网 | 前后端持久化和异常路径有自动测试 | 保留请求身份和未知状态，不自动重复操作 |
| 桥接服务重启 | 已有实际重连与持久化测试 | 恢复会话读取，发送回执仍可查 |
| 启动它的宿主退出 | 已有 Windows Job 终止测试 | 桥接独立存活；仍需真实桌面升级场景验收 |
| Codex 桌面升级或内部协议变更 | 部分覆盖 | 分清服务离线和协议不兼容；不能把错误表现成空白或发送成功 |
| 桥接进程退出 | 已实现独立守护与逐步退避恢复 | 核对实际恢复结果，关闭自动恢复后不重新拉起；不重发消息 |
| Windows 登录后启动桥接 | 已实现可选的当前用户登录启动项 | 默认关闭；开启/关闭及实际注册状态可从网页查看；真实重启登录尚待验收 |
| Codex 桌面未启动、登录前、睡眠、断电 | 不在当前目标条件内 | 当前用户要求电脑与Codex已运行；本项目不提供唤醒与自动登录 |
| 守护自身退出 | 未自动恢复 | 仍可能需要从本机后台入口重新启动 |

## 外网入口

已接入可选的 Cloudflare Quick Tunnel 临时 HTTPS 地址和独立登录网关。无需自有域名、VPS或手机软件；从本机“手机访问设置”明确开启，生成一次性显示的随机口令。认证、来源检查、设备退出与全部登录撤销、网关会话恢复和写操作不重放有自动测试。

临时域名可能晚于隧道连接注册生效。网页仅在网关监听、隧道注册和系统 DNS 解析成功后显示网址；DNS 等待期间保留已连接的隧道，不因超过连接注册的 60 秒期限而换网址。每次 DNS 等待最多 1 秒，停止操作仍会生效；若域名一直未生效，会继续显示等待状态。

最终实际外网 HTTPS 验收使用普通 fetch 与系统 DNS，约 75 秒后就绪，完成未登录拒绝、登录、桌面会话读取、本机配置入口隔离与退出后拒绝验证。早期验收曾使用专用 HTTPS DNS 解析；最终验收没有使用该方式，也没有修改电脑 DNS 设置。成功后临时入口保持运行；口令未写入证据文件。网页交互用 jsdom 驱动实际前端模块，真实手机网络、触摸和视觉仍需验收。临时地址随隧道重建可能改变，人在外面无法获知新地址的问题仍需后续稳定入口解决。

真实桌面、模拟协议、DOM 模拟器和真实手机浏览器的结果分别记录在 [verification.md](verification.md)。通过某一层不代表其他层已经验证。
