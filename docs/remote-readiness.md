# 远程使用条件

手机和电脑使用同一个 HTTPS 服务入口。电脑需要开机、联网并已登录 Windows，Codex 桌面和连接器都需要运行。连接器的登录后自动连接可等待 Codex；它不自动登录 Windows、启动 Codex 或唤醒睡眠电脑。

电脑离线时不能发送新请求。连接恢复后可继续读取会话；结果未知的发送、创建或审批应先查询回执，避免重复提交。

页面轮询同步历史和状态，不提供逐 token 流。子智能体内容仅供只读查看。可用模型、权限和交互类型取决于当前 Codex 桌面接口，升级桌面后可能需要更新连接器。

长期使用推荐管理员提供的 HTTPS Hub。源码临时访问可以使用 [Quick Tunnel](temporary-mobile-access.md)，网址可能随隧道重建而改变。
