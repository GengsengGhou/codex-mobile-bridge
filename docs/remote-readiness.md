# 远程使用条件

手机浏览器通过 Hub 访问已配对电脑上的 Codex 会话。电脑需开机并联网，用户需登录 Windows，Codex 桌面和连接器需运行。连接器不会自动启动 Codex，也不能登录 Windows、唤醒睡眠或恢复断电的电脑。

## 连接中断

连接器与 Hub 之间由电脑主动建立加密连接。暂时断网时，手机页面可能无法读取最新状态或提交操作；恢复网络后先刷新状态，并通过操作回执确认结果。消息、审批、新建会话和文件提交不会因为断线而自动重复。

如果 Hub 显示设备在线但 Codex 不可用，先确认 Codex 桌面已打开并有可用的普通会话。桌面内部接口可能随 Codex 更新变化；连接器可达不代表每项桌面操作都可用。Windows 侧网络故障可使用[配对网络诊断](network-diagnostics.md)。

## 临时入口

源码版可选 Quick Tunnel 提供临时 HTTPS 入口，适用于单台自己的电脑，不需要自有域名或 VPS。临时地址可能改变；需要长期使用、多账号和设备管理时，部署 VPS Hub。具体条件见[临时手机访问](temporary-mobile-access.md)和[Hub 部署指南](native-vps-deployment.md)。
