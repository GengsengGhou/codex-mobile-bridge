# 更新恢复（v3.0.0）

v3.0.0 修复 Windows 时间和网络/VPN 恢复正确后的更新检查。无需更新 Hub 或重新配对。

1. 在 Windows 设置中核对日期、时间和时区，需要时同步时间。
2. 恢复能访问 GitHub 的网络和 VPN。
3. 打开连接器设置并点击“检查更新”。检查期间优先显示进行中状态。若提示已有更新操作，等待完成后再次点击；这次点击明确报告忙碌，不代表又一次版本信息验证失败。
4. 发现新版本后可选择下载并升级；也可从官方 Release 手动下载相应安装器和 SHA-256 清单，核对后在原目录升级。普通升级保留配对、授权及本机设置，完成后完全退出并重新打开 Codex。

手动检查绕过自动检查开关和重试间隔，但不抢占已有检查或下载。每次成功开始的手动检查都重新请求官方信息，不会仅返回旧缓存错误。自动检查通常在成功后一天或失败后一小时重试，恢复系统时间后仍可正常继续。

更新继续使用 GitHub 官方来源和默认 TLS 验证；每次下载重新验证发布信息，并核对稳定版本、安装包来源、大小、SHA-256 与文件格式。移除官方发布时间与本机时钟的比较，不会取消这些完整性检查。

证书日期失败提示核对时间；网络/VPN 失败提示恢复后重试；发布信息或安装包验证失败提供对应错误。无需为更新重新配对、重置协作授权或删除数据。

GitHub 更新与 VPN 仍需要正确的系统时间；连接器的 Hub 时钟兼容不覆盖它们，也不会调整 Windows 时间。本次修复不借用 Hub 时间，不使用镜像、代理转发或证书绕过。
