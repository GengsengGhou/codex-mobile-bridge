# 验证与兼容

发行验收检查安装器与包内版本、源码载荷一致性、SHA-256 清单、运行依赖与许可，以及隔离目录中的实际安装、状态读取和卸载。对应发行资产见 [v1.0.0 Release](https://github.com/GengsengGhou/codex-mobile-bridge/releases/tag/v1.0.0)。

这些检查不代表所有实体手机、Windows 登录环境或未来 Codex 桌面版本都已验证。项目依赖桌面内部接口，更新后可能需要适配；遇到问题请附软件版本、现象和不含账号、邀请或配对信息的错误提示。

维护者验证入口与构建说明见[开发指南](development.md)。详细机器日志、截图和隔离运行记录保存在忽略目录，不随发行包分发。
