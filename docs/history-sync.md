# 会话与历史同步

会话页加载当前消息，并保留已读取的历史。点击历史边界的“更早消息”可继续按页读取；读取失败时，已显示内容和游标会保留，可重试。切换会话不会把旧会话的迟到响应合并进当前页面。

页面按任务状态调整刷新频率。运行中任务、待处理问题、未确认提交和连接不可用时较频繁读取；空闲时延长间隔。切到后台会暂停定时读取，返回页面或网络恢复后刷新状态。当前页面只显示快照，不提供逐 token 实时流。

历史与状态更新按账号、设备、完整会话 ID 和分页游标隔离。读取失败不会清空已有历史或草稿。桌面拒绝工具输出时，可降级读取不含工具输出的同一页面；这只影响读取，不会替代或重试发送、审批、创建等写操作。

提交结果未知时，页面会保留请求记录并查询原回执；断线、刷新或重新打开页面都不会自动重发。请先确认原操作的状态，再决定下一步。错误和权限边界见[协议说明](protocol-notes.md)。
