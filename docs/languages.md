# Language and product name

The product is named **Codex Mobile Bridge** in both Chinese and English. Windows
uses this name for the desktop shortcut, Start menu entry, app window, installer
and installed-app list. The existing installation directory and device pairing
continue to work when upgrading.

## Web

Use the language selector to choose **中文** or **English**. The first visit follows
the browser's language; an explicit selection is remembered in that browser.
The device portal and conversation pages share the same choice on one server.
Changing language keeps the current conversation and unsent drafts.

Conversation content, project names, device names, file contents and model names
keep their original text. Interface labels and status messages change language.

## Windows

Choose a language in the installer before installing or upgrading. After
installation, change it again from the app's Settings / 设置 page. The selected
language is remembered for the current installation. Changing it does not pair
the computer again or restart its connection.

The web and Windows app can use different languages. Neither choice changes
the language of the messages sent to Codex.
