# Codex 手机桥接

通过正在运行的 Codex 桌面任务接口读取与发送消息，复用桌面的模型与配置，不需要在网页填写模型密钥。本项目是实验性的非官方客户端，桌面内部接口升级后可能需要重新适配。

源码仓库：[GengsengGhou/codex-mobile-bridge](https://github.com/GengsengGhou/codex-mobile-bridge)。安装包与校验清单：[发行版本](https://github.com/GengsengGhou/codex-mobile-bridge/releases)。公开仓库与 Release 可直接下载；源码下载不授予桥接服务账号，使用已有服务仍需管理员邀请。

## 开始使用

| 你的情况 | 下一步 |
| --- | --- |
| 有自己的 VPS，希望独立运行服务 | 按 [Ubuntu / Debian 部署教程](docs/native-vps-deployment.md) 配置自己的域名、HTTPS 和管理员，再安装电脑连接器。也有 [Docker Compose 方案](docs/compose-deployment.md)。 |
| 受邀使用已有服务，不部署 VPS | 向服务管理员私下获取入口网址和一次性邀请，按 [受邀使用与电脑配对](docs/quick-start.md#受邀使用已有服务) 注册并安装连接器。 |

[简易配置教程](docs/quick-start.md) 汇总下载、账号、设备配对和排错。仓库与安装器不预设运营者的实际 VPS 域名或 IP；受邀用户仍需知道管理员提供的入口网址。邀请用于注册账号，设备配对码用于绑定电脑，不能混用。

## 已实现

- 同一桌面任务的列表、消息、运行状态和历史分页；运行中或有待处理交互时约每3秒同步，空闲时逐步退避到10–30秒，页面隐藏时暂停，回到页面或提交操作后立即更新。未变化的快照使用条件响应减少流量。
- 大字手机排版、任务搜索、项目文件夹和置顶区域，记住所选任务及各任务草稿。侧栏只显示会话标题及必要的运行状态。
- 输入框旁“沿用桌面”可选择下一轮的模型与推理强度，新建会话也可选择。默认不传覆盖参数，沿用桌面；可选组合从当前桌面工具目录读取，不固定模型清单。选择按本浏览器用户、设备、会话与草稿一样隔离保存。正在运行时补充消息仍沿用运行中的模型，所选设置用于下一轮；如果发送前会话恰好开始运行，则明确拒绝切换并保留草稿，不自动重发。
- 输入区的权限菜单可为下一轮选择“完全访问 / 请求批准”，默认继承桌面。运行中补充仍沿用当前轮次权限，选择保留到下一轮；不兼容的桌面明确拒绝显式覆盖。新建会话暂不提供权限覆盖。
- 对话上方的右栏图标显示当前权限、Git、工作目录、已识别代理和信息来源；桌面为右列、手机为可关闭面板，默认收起。来源包括已载入历史中的附件、网页和工具，不保证完整。详情与兼容边界见 [会话上下文与权限](docs/thread-context-permissions.md)。
- 侧栏“新建会话”可选择桌面已保存的本机项目或“无项目”，填写可选标题和首条消息；默认使用桌面模型设置创建普通会话。仅在开启本机全部会话范围且桌面接口支持时开放。首条消息随创建提交一次，成功后通过真实会话 ID 继续交流。
- 会话菜单支持原生重命名、置顶/取消置顶与归档，同步到桌面。归档需确认，只开放未运行的会话，启动桥接的会话不可归档；侧栏底部“归档会话”支持分页查看、确认恢复，再刷新普通会话列表。恢复范围沿用发送范围，未知结果不会自动重试。旧版浏览器置顶覆盖在对该会话执行原生置顶操作后清除。
- 按桌面保存的项目归属统一分组与排序；支持折叠项目，搜索时自动展开匹配结果。
- 侧栏点击“排序”，用手柄拖动项目或组内会话，也可用上下按钮或键盘方向键调整。顺序自动保存在桥接服务，不同网页共用；“跟随桌面”清除网页排序。此操作不会修改桌面原版侧栏顺序，也不改变会话所属项目。
- 切换会话先恢复本页已读缓存、草稿和阅读位置，再更新最新内容；取消旧读取并忽略迟到结果。缓存最多20个会话、合计1000轮，刷新网页后重新读取。
- 用户消息靠右，模型回复靠左；工具活动和过程说明默认折叠，手动展开状态在轮询时保留。
- 桌面稳定消息 ID 在轮次间移动时更新缓存归属，避免旧缓存重复显示补充消息；迟到历史页不能覆盖最新归属，同文但不同 ID 的有意发送仍保留。
- 隐藏已识别的系统注入浏览器上下文、附件提示和问答封装，保留真实输入及用户主动引用的标记；创建任务标记显示为可读文字。
- 点击对话上方的“字号”打开字体设置：10–48 px 滑杆、放大/缩小、即时预览、恢复默认20px。正文、代码、表格、输入框和工具活动随之缩放；保留阅读位置，并在本浏览器记住选择。
- 安全 Markdown 子集：标题、段落、列表、粗体、行内代码、代码块、表格、网页链接；代码复制。不是完整 CommonMark 实现。
- LaTeX 公式支持 `$...$`、`$$...$$`、`\(...\)` 和 `\[...\]`，使用本地 KaTeX 排版；代码与价格保留原文。公式跟随字号设置，长公式在自身区域横向滚动。支持范围、限制与验收见 [docs/math-rendering.md](docs/math-rendering.md)。
- 会话文件面板可浏览当前工作目录、返回上级、刷新，查看文件大小；聊天里的本地文件链接可打开同一预览入口。支持文本、图片与 PDF 预览，以及文件下载。目录外文件不会自动开放；这不是全部生成产物的自动索引。
- 输入框旁“＋”选择附件，每个会话最多暂存5个，每个不超过20 MiB。文件先上传到该会话工作目录下的 `mobile-uploads/<上传编号>/<文件名>`，上传本身不会发送消息；点击发送后，把说明与本地文件链接交给同一桌面会话，也支持只发送附件。当前通过文本提示让模型读取本地文件，不是原生多模态附件输入块。
- 附件上传核对实际大小与SHA-256，独立目录与排他提交避免覆盖。上传回执跨桥接重启保留；丢失回执或刷新后只查询结果。暂存附件随会话切换保留，发送前重新核对文件；恢复记录损坏或无法保存时阻止提交，并提供重试读取/明确清除记录的入口。“移除”仅从待发送列表移除，不删除电脑上的文件。
- 支持向本机普通 Codex 会话发送消息及运行中补充；桌面接收后返回回执，回复同步到网页。可配置单会话发送范围或关闭发送。
- 修复桌面把跨任务输入存成工具消息导致网页漏掉用户输入的问题。
- 运行控制读取当前活动轮次，显示“停止”按钮；提交前再次核对轮次与桌面运行实例，拒绝用旧轮次停止新任务。
- 待处理交互显示具体命令、工作目录、文件差异或问题选项；支持此次允许、拒绝、标准问题与异步问题回答。仅完整识别且仍有效的请求可提交；额外权限、策略变更及未知类型明确禁用。桌面收到提交不等于已经应用，网页继续核对请求状态。
- 待处理交互默认为紧凑可展开入口，收起后轮询与刷新保持收起；长问题正文独立滚动，提交按钮保持可见。明确属于旧轮次的问题移入“任务详情 / 历史提问”，可关闭或重新查看，不再常驻顶部。
- 问题草稿在轮询、切换和刷新时保留；敏感答案不写入浏览器存储。回复前保存提交状态，断线或结果未知时不自动重发；控制快照暂不可用时保留并禁用卡片。问题、选项、命令和差异随字号设置缩放。
- 发送前保存请求 ID，桌面接收后保存回执；相同请求 ID 跨桥接重启去重。发送结果不明时，网页只查询回执，不自动重发。浏览器无法保存恢复记录时阻止发送，保留草稿。
- 适配 Codex 26.924.1866.0 的请求来源字段；健康检查实际读取任务。Windows 连接断开后自动发现当前桌面 pipe；接口不兼容、桌面离线和桥接离线分别提示。
- 桥接重启后，已打开的网页可自动续期会话并恢复只读轮询；发送不自动重试。
- 侧栏底部“运行与恢复”可查看后台守护状态、恢复次数与最近错误，调整“Windows 登录后启动桥接”和“桥接退出后自动恢复”。登录启动默认关闭，只有明确开启才写入当前用户的启动项；设置保存断线后仅查询当前值，不自动重复提交。
- 本机侧栏“手机访问设置”支持明确开启/关闭临时 HTTPS 入口，无需自己的域名、VPS 或手机应用。开启时显示随机访问密码；手机登录后继续使用相同桌面会话。独立网关要求登录并限制来源，不把本机自动会话入口直接暴露给隧道。支持退出和撤销全部登录，登录过期后保留草稿并阻止自动重发。

2026-09-25 已在用户授权的“手机桥接验收”任务完成真实适配器和 HTTP 往返：同一任务 ID 收到标记并回复；重复 HTTP 请求只产生一轮。实际发送只针对该测试任务，未向业务任务发送测试消息。

## 运行

本机桥接使用 Node.js 22.16+，不需要第三方 npm 运行依赖；Hub 与设备连接器使用 ws（发布包已包含）。从 Codex 桌面任务环境启动：

```powershell
Set-Location 'C:\projects\codex-mobile-bridge'
$env:BRIDGE_ENABLE_SEND = '1'
$env:BRIDGE_SEND_SCOPE = 'all-local'
npm start
```

访问 http://127.0.0.1:4317/ 。初次默认不开启发送，以上配置开放本机普通会话。若只开放指定会话，设置 `BRIDGE_SEND_SCOPE=single` 与 `BRIDGE_SEND_THREAD_ID`；设置 `BRIDGE_ENABLE_SEND=0` 关闭发送。`BRIDGE_PORT` 可覆盖端口。配置会保存供后续启动使用。

首次从桌面任务启动时，保存任务ID、端口和发送范围到忽略版本控制的 `.local/runtime.json`，不保存密钥和 pipe 地址。此后可在项目目录双击 `启动手机桥接.cmd`，或运行 `npm run start:background`，从普通终端启动隐藏后台服务。

该发送范围也约束会话管理、停止、审批与回答操作。命令行服务将发送及交互提交记录保存在 `.local/deliveries.json`，只含请求ID、会话ID、内容指纹与回执，不保存消息正文或回答内容。网页待核对消息和非敏感草稿保存在当前标签页的会话存储中。开发时 `createBridgeServer` 默认使用隔离的内存记录；需要持久化时必须注入 `DeliveryStore`，生产入口已注入。

新建会话使用独立的 `.local/thread-creations.json`，记录请求 ID、内容哈希和真实会话回执，不保存首条消息正文。创建结果未知时只查询原请求回执，不自动重新创建。创建记录读取失败不影响已有会话列表；刚创建会话的补充读取有短时间预算，不拖住原生列表。

附件记录保存在独立的 `.local/uploads.json`，只包含文件标识、名称、大小、内容指纹、工作目录与回执，实际文件位于对应会话目录。最多保留500条上传记录，按声明大小累计最多1 GiB；未完成的保留记录也占额度，不自动删除已上传文件。开发时嵌入式服务器默认用内存上传记录，生产入口显式启用持久化记录。

Windows 后台启动通过 WMI 进程代理创建隐藏守护进程，脱离启动它的 Codex Job Object；普通 `detached` 子进程不能提供这种保证。启动失败会明确报错，不退回原先容易随宿主退出的方式。后台启动默认在桥接退出后自动恢复，连续失败逐步延长重试间隔。不会因 Codex 暂时离线而重启桥接，也不会重新发送聊天消息。

服务会只读识别当前 Codex app-tools pipe。桌面暂未打开时，网页仍可打开并等待连接；若发现多个可用桌面连接，则提示重新从目标桌面任务启动，不随意选取。后台日志在 `.local/bridge.stdout.log` 和 `.local/bridge.stderr.log`。停止服务前通过4317监听进程核对命令行确实指向本项目，旧预览PID记录不能作为停止依据。前台运行可 Ctrl+C 停止。

“Windows 登录后启动桥接”使用当前用户独立命名的启动项，无需管理员权限，不安装系统服务。关闭开关只移除本项目拥有的启动项，不停止当前桥接。关闭自动恢复后，当前桥接继续运行，退出后不再自动拉起。前台 `npm start` 不受后台守护；页面会明确显示未托管，需要从后台启动入口重新启动才能获得崩溃恢复。

登录启动需要电脑已开机、用户已经登录 Windows。Codex 桌面仍需运行；本功能不自动开启 Codex，不提供登录前控制、睡眠唤醒或断电恢复。后台守护自身被终止、Node 路径失效或 Windows 禁用启动项也可能需要本机处理。尚未以主动更新/重启正在使用的 Codex 做验收，不能承诺未来内部接口始终兼容。

## 当前边界

- **临时手机入口需从本机设置明确开启**。本机桥接监听 127.0.0.1:4317，认证网关监听 127.0.0.1:4318，由 Cloudflare Quick Tunnel 提供外网 HTTPS 地址。临时域名会随隧道重新建立改变，不适合作为长期固定收藏地址；未完成真实手机网络/浏览器验收。
- 逐字事件流尚未接入网页。附件上传用于已有会话，新建表单尚不能直接携带附件；可先创建再上传。工作目录内已有文件可查看或下载，Word、Excel 等格式需下载后用对应应用打开。审批和问题回答只支持已适配的请求格式，验收范围见 `docs/verification.md`。运行中补充由桌面接收和调度；停止使用桌面原生中断行为，不保证能撤销已经发生的工具操作。
- 普通列表显示原生最近最多50个普通任务、置顶任务以及有限的新建任务补充；归档列表独立分页，每页30项。尚不支持远程主机/ChatGPT 会话。新建只支持已保存本机项目或无项目，不支持任意目录、worktree或云端创建。
- 内部 app-tools 与 codex-ipc 接口可能随桌面升级变化，不是官方承诺稳定的远程客户端接口。控制接口不兼容时禁用停止，保留读取聊天能力。
- 项目归属还会只读提取 `CODEX_HOME/.codex-global-state.json` 的侧栏字段（默认用户 `.codex` 目录）；不修改桌面设置、不转发完整状态。该内部格式也可能变化，缺失时退回接口元数据。
- 持久化去重依赖同一请求 ID 与保留的发送记录；不承诺端到端恰好一次。桌面已接收但回执保存前退出时仍需人工核对。单桥接实例支持串行记录写入，勿用多个桥接进程共享同一记录文件。当前记录上限1000条，不自动删除未知记录，达到上限会停止接收新发送。
- 首屏和历史页每页最多10轮；“较早的消息”在对话已载入记录的顶部，点击加载并保持阅读位置，读取失败可手动重试，全部读完显示“已到最早消息”。长期断线后的历史补齐有分页上限，未完整载入的部分仍需继续加载历史。
- HTML 原样作为文字显示；本地文件链接经认证接口读取，仅限当前会话的工作目录。点号开头的文件/目录、常见凭据文件和符号链接等受限路径不会开放，不支持任意磁盘或网络共享浏览。目录最多检查 1500 项、返回 300 项，超出时明确提示结果不完整。文本预览上限 1 MiB、图片 20 MiB、PDF 30 MiB、下载 100 MiB；PDF 能否内嵌显示取决于手机浏览器，可改用下载。

## 接入方式

读取、普通发送和会话管理使用桌面 app-tools named pipe（4 字节长度前缀 + JSON-RPC）；停止、运行状态和待处理交互使用现有 codex-ipc 的握手、会话所属实例发现、快照订阅与对应原生操作。没有另外启动 Codex 执行引擎或复制会话数据库，不开放任意 RPC。

离开电脑后的功能与恢复验收清单见 [docs/remote-readiness.md](docs/remote-readiness.md)。本项目当前使用条件是电脑已开机、联网且 Codex 已运行；自动开启 Codex、登录前控制和睡眠唤醒不属于本轮目标。

## 临时手机访问

当前电脑已安装经官方发布 SHA-256 校验的 cloudflared 2026.9.3，位置为忽略版本控制的 `.local/tools/cloudflared.exe`。其他电脑可运行 `npm run remote:install` 安装到项目内，不改 PATH、不注册系统服务。

1. 打开本机网页，侧栏进入“手机访问设置”，点击“开启手机访问”。
2. 保存只在当前页面显示的访问密码，等待临时 HTTPS 地址就绪；首次域名生效可能需要几十秒。
3. 手机浏览器打开该地址，用访问密码登录。刷新本机页面不会重新显示原密码；已保存的原密码仍有效。遗失时需关闭入口后重新开启，生成新密码。
4. “退出登录”只撤销当前设备；“撤销全部登录”会让所有设备重新登录。关闭手机入口会结束隧道并撤销登录，下次开启生成新密码。

密码以加盐 scrypt 保存，登录会话只保存令牌哈希，最长7天、最多10个；有全局登录尝试限流。`.local/remote-auth.json` 不保存明文口令或会话令牌。登录设置仅从本机入口开放，远程网关不转发该设置接口。登录请求丢失响应、隧道断线和桥接重启均不会自动重发聊天操作。

隧道由独立后台进程维持，断开后重建并更新本机设置中的地址；临时地址改变时，手机旧收藏无法自动找回新网址。它用于首次远程试用，长期“随时随地”访问仍需要后续稳定地址方案。不要把4317本机服务直接映射到公网；实际隧道仅连接带独立登录保护的4318网关。

## 固定入口与多电脑

部署自己的 HTTPS 入口（例如 `https://codex.example.com`）后，账号登录只能进入自己配对的电脑，注册需要管理员邀请。电脑主动连接 VPS，不需公网 IP 或开放路由器端口。可使用 Caddy 和专用 systemd 服务，也提供 Docker Compose 配置。

Windows 用户双击 `dist/CodexMobileConnector-Setup.exe`，无需管理员权限或手动安装 Node.js。安装到当前用户后，在网页设备页生成并复制一次性配对信息 JSON，再粘贴到中文窗口，核对服务器、设备名称和有效期后确认。安装器不预设个人域名；发布构建内置校验过官方 SHA256 的 Node.js 和 ws。可先配对再打开 Codex，程序会等待并只读选择可用的现有普通本机会话，不创建或发送任务。账号密码不保存，设备凭据保存到私有 ACL 保护的 `.local/hub-connector.json`。窗口提供状态、重试、打开 Codex 与设置；更换服务器需明确勾选替换配对，验证失败保留旧凭据。卸载默认保留 `.local` 数据；已有安装会拒绝覆盖，保留数据卸载后可重装。旧 ZIP 与 `deploy/install-connector.cmd` 仍可用于终端安装，需打开 Codex 并在交互终端选择启动会话。图形安装与校验见 [docs/windows-installer.md](docs/windows-installer.md)。

首次成功配对默认开启当前 Windows 用户的登录后自动连接（配对前明确关闭时保留关闭），并启动 WMI 独立后台监测等待 Codex。窗口右上角 X 只隐藏到托盘，可从托盘恢复窗口；主动“退出”会停止本安装拥有的监测和连接器，手机入口随之离线，不停止独立桥接、Codex 或其正在运行的任务。下次登录会按自动启动设置恢复，除非此前已执行跨登录持久断开；普通打开窗口只查看状态，需明确执行“连接”才会恢复。

设置中可明确开启或关闭当前用户的 Windows 登录后自动连接。开启后，下次登录 Windows 会隐藏启动到托盘并恢复监测、等待 Codex；它不是登录前控制，也不会自动开启 Codex、唤醒睡眠或恢复断电。关闭开关取消之后的登录自动连接，不改变当前连接；本次主动退出只暂停当前登录会话，不清除已保存的自动选择，下次登录仍按该选择运行。“断开连接”则跨登录持久暂停，之后需明确点击“连接”恢复。已有新版偏好或仍可确认本安装拥有的旧登录入口时保留自动选择；旧 v0.1.0 卸载会移除其登录设置，保留配对重装后需重新核对、按需要勾选自动连接开关。高级 ZIP / 源码 CLI 的显式登录注册入口仍保留旧自动模式，见安装说明。

首次身份验证并保存后清除待配置授权，后续只恢复保存的会话身份与发送范围；旧安装配置缺失或损坏不会自动授予新身份。当前用户登录任务（不提升权限）和启动项通过同一互斥锁合并为一个监测，每 10 秒检查桥接和连接器；网络离线由连接器重连，不重新配对或发送聊天消息。移动安装目录或 Node 后需保留数据重新安装。独立命名的任务与启动项不会替换其他程序命令。启动诊断见 `.local/connector-login-bootstrap.log` 和 `.local/connector-login.*.log`，状态见 `.local/hub-connector-state.json`；这些日志不包含设备令牌。

已完成公网 HTTPS 登录、后台 WSS 连接和真实会话只读验收；实体手机触摸及第二台实际电脑尚未验收。发布包和 SHA256 清单保存在 `dist/`，不进入源码仓库。部署、隔离、安装与启动条件见 [docs/vps-device-hub.md](docs/vps-device-hub.md)，原生 VPS 操作见 [docs/native-vps-deployment.md](docs/native-vps-deployment.md)。
